# Cybersecurity Lab Documentation

This repository contains documentation from hands-on cybersecurity labs performed in authorized training environments. The reports focus on both offensive security techniques and defensive monitoring, demonstrating how attacks can be detected and investigated using SIEM technologies.

## Topics Covered

- Web Application Security Testing
- Privilege Escalation
- Path Traversal / Local File Inclusion
- Linux Enumeration
- Incident Detection and Monitoring
- SIEM Alert Analysis
- Kibana Dashboards
- Wazuh & Security Onion
- Zeek and Suricata Logs
- MITRE ATT&CK Mapping
- Detection Engineering

> **Disclaimer:** All activities documented in this repository were conducted in authorized lab environments (e.g., CTFs, training platforms, and virtual machines) for educational purposes only.
